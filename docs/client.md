# Client

- `Mojang` [site](https://minecraft.net/ru-ru/download) - Официальный сайт. Требуется лицензия.
- `Prism Launcher` [site](https://prismlauncher.org/download) / [github](https://github.com/PrismLauncher/PrismLauncher) - Лаунчер с менеджером инстансов, нативная сборка под Apple Silicon. Требуется лицензия.
- `MultiMC` [site](https://multimc.org) / [github](https://github.com/MultiMC/MultiMC5) - Лаунчер с изолированными инстансами и отдельными настройками. Требуется лицензия.
- `Modrinth` [site](https://modrinth.com/app) / [github](https://github.com/modrinth/code) - Лаунчер с каталогом модов и сборок Modrinth. Требуется лицензия.
- `Millida` [site](https://millida.net/launcher) / [github](https://github.com/oleg4016/milida-launcher) - Лаунчер с модами, сборками и отдельными инстансами.
- `CurseForge` [site](https://www.curseforge.com/download/app) - Лаунчер с каталогом модов и сборок CurseForge. Требуется лицензия.
- `Legacy Launcher` [site](https://llaun.ch) / [mirror](https://lln4.ru) - Бесплатный лаунчер, работает без лицензии.
