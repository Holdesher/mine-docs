# Utils

## Tools

- `Baritone` [github](https://github.com/cabaletta/baritone) - Бот-навигация: автоматические маршруты, добыча, стройка и поиск по командам.
- `Amulet` [site](https://amuletmc.com) / [github](https://github.com/Amulet-Team/Amulet-Map-Editor/releases) - Офлайн-редактор и конвертер миров Java/Bedrock.
- `World Downloader` [site](https://pokechu22.github.io/WorldDownloader) / [github](https://github.com/Pokechu22/WorldDownloader/releases) - Скачивание мира с сервера для одиночной игры.
- `MCBuild Schematics` [site](https://mcbuild.org/schematics) - Библиотека схематик для `Litematica` и `WorldEdit`.
- `MineSchematic` [site](https://mineschematic.com) - Библиотека схематик с 3D-превью.

## Cheats

- `Impact Client` [site](https://impactclient.net) - Закрытый чит-клиент для `Forge`, утилиты и эксплойты.
- `Meteor Client` [site](https://meteorclient.com) / [github](https://github.com/MeteorDevelopment/meteor-client) - Open-source чит-клиент для `Fabric`, десятки модулей для анархии.
- `Wurst Client` [site](https://wurstclient.net) / [github](https://github.com/Wurst-Imperium/Wurst7) - Бесплатный чит-клиент для `Forge` и `Fabric`, широкий набор хаков и простой интерфейс.
- `LiquidBounce` [site](https://liquidbounce.net) / [github](https://github.com/CCBlueX/LiquidBounce) - Open-source чит-клиент, заточен под PvP и обход античитов.
