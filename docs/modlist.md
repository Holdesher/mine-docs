# ModList

- `Fabric API` [modrinth](https://modrinth.com/mod/fabric-api) - Базовая библиотека для Fabric-модов.
- `Sodium` [modrinth](https://modrinth.com/mod/sodium) - Ускоряет рендеринг для повышения FPS.
- `Mod Menu` [modrinth](https://modrinth.com/mod/modmenu) - Меню для просмотра и настройки модов.
- `Iris Shaders` [modrinth](https://modrinth.com/mod/iris) - Поддержка шейдеров на Fabric.
- `Xaero's World Map` [modrinth](https://modrinth.com/mod/xaeros-world-map) - Динамическая карта мира.
- `Xaero's Minimap` [modrinth](https://modrinth.com/mod/xaeros-minimap) - Динамическая мини-карта мира.
- `ReplayMod` [modrinth](https://modrinth.com/mod/replaymod) - Запись игрового процесса.
- `Malilib` [modrinth](https://modrinth.com/mod/malilib) - Мод-библиотека для клиентских модов.
- `Litematica` [modrinth](https://modrinth.com/mod/litematica) - Схемотехнический мод.
- `WorldEdit` [modrinth](https://modrinth.com/plugin/worldedit) - Редактирование зон отображений.
- `Simple Voice Chat` [modrinth](https://modrinth.com/plugin/simple-voice-chat) - Голосовой чат в игре.
- `Nemo's Inventory Sorting` [modrinth](https://modrinth.com/mod/nemos-inventory-sorting) - Сортировка и фильтраци инвенторя.
- `Distant Horizons` [modrinth](https://modrinth.com/mod/distanthorizons) - Прогрузка чанков.
- `Concurrent Chunk Management Engine` [modrinth](https://modrinth.com/mod/c2me-fabric) - Оптимизация прогрузки чанков.
