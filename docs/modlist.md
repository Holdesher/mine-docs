# ModList

## Fabric

- `Fabric API` [modrinth](https://modrinth.com/mod/fabric-api) / [curseforge](https://curseforge.com/minecraft/mc-mods/fabric-api) / [github](https://github.com/FabricMC/fabric-api) - Библиотека API, требуется большинству Fabric-модов.
- `Sodium` [modrinth](https://modrinth.com/mod/sodium) / [curseforge](https://curseforge.com/minecraft/mc-mods/sodium) / [github](https://github.com/CaffeineMC/sodium) - Переписывает рендеринг Minecraft,значительно повышает FPS.
- `Mod Menu` [modrinth](https://modrinth.com/mod/modmenu) / [curseforge](https://curseforge.com/minecraft/mc-mods/modmenu) / [github](https://github.com/TerraformersMC/ModMenu) - Список установленных модов с доступом к их настройкам.
- `Iris Shaders` [modrinth](https://modrinth.com/mod/iris) / [curseforge](https://curseforge.com/minecraft/mc-mods/irisshaders) / [github](https://github.com/IrisShaders/Iris) - Загрузчик шейдеров, совместим с пакетами OptiFine.
- `Xaero's World Map` [modrinth](https://modrinth.com/mod/xaeros-world-map) / [curseforge](https://curseforge.com/minecraft/mc-mods/xaeros-world-map) - Полноэкранная карта всего посещённого мира.
- `Xaero's Minimap` [modrinth](https://modrinth.com/mod/xaeros-minimap) / [curseforge](https://curseforge.com/minecraft/mc-mods/xaeros-minimap) - Мини-карта с метками, сущностями и точками интереса.
- `ReplayMod` [modrinth](https://modrinth.com/mod/replaymod) / [github](https://github.com/ReplayMod/ReplayMod) - Запись игры с просмотром реплея и рендерингом видео.
- `Malilib` [modrinth](https://modrinth.com/mod/malilib) / [curseforge](https://curseforge.com/minecraft/mc-mods/malilib) / [github](https://github.com/maruohon/malilib) - Библиотека, нужна Litematica и другим клиентским модам.
- `Litematica` [modrinth](https://modrinth.com/mod/litematica) / [curseforge](https://curseforge.com/minecraft/mc-mods/litematica) / [github](https://github.com/maruohon/litematica) - Строительство по схематикам: призрачный чертёж и список недостающих блоков.
- `WorldEdit` [modrinth](https://modrinth.com/plugin/worldedit) / [curseforge](https://curseforge.com/minecraft/mc-mods/worldedit) / [github](https://github.com/EngineHub/WorldEdit) - Массовое редактирование мира: копирование, замена, геометрические фигуры.
- `Simple Voice Chat` [modrinth](https://modrinth.com/plugin/simple-voice-chat) / [curseforge](https://curseforge.com/minecraft/mc-mods/simple-voice-chat) / [github](https://github.com/henkelmax/simple-voice-chat) - Голосовой чат на серверах: каналы, группы, прокси-сервер.
- `Nemo's Inventory Sorting` [modrinth](https://modrinth.com/mod/nemos-inventory-sorting) / [curseforge](https://curseforge.com/minecraft/mc-mods/nemos-inventory-sorting) / [github](https://github.com/NemoNotFound/NemosInventorySorting) - Сортировка инвентаря и контейнеров по заданным правилам.
- `Distant Horizons` [modrinth](https://modrinth.com/mod/distanthorizons) / [curseforge](https://curseforge.com/minecraft/mc-mods/distant-horizons) / [gitlab](https://gitlab.com/distant-horizons-team/distant-horizons) - Дальние чанки рисуются упрощёнными LOD-моделями.
- `Concurrent Chunk Management Engine` [modrinth](https://modrinth.com/mod/c2me-fabric) / [curseforge](https://curseforge.com/minecraft/mc-mods/c2me) / [github](https://github.com/RelativityMC/C2ME-fabric) - Многопоточная загрузка и генерация чанков.

## NeoForge

- `NeoForge API` [site](https://neoforged.net) / [github](https://github.com/neoforged/NeoForge) - Загрузчик модов для 1.21.1 (ставится лаунчером, отдельный jar не нужен).
- `Sodium` [modrinth](https://modrinth.com/mod/sodium) / [curseforge](https://curseforge.com/minecraft/mc-mods/sodium) / [github](https://github.com/CaffeineMC/sodium) - Переписывает рендеринг Minecraft,значительно повышает FPS.
- `Sodium Extra` [modrinth](https://modrinth.com/mod/sodium-extra) / [curseforge](https://curseforge.com/minecraft/mc-mods/sodium-extra) / [github](https://github.com/FlashyReese/sodium-extra-fabric) - Настройки анимаций, частиц и деталей, которых нет в Sodium.
- `Sodium Leaf Culling` [modrinth](https://modrinth.com/mod/sodiumleafculling) / [curseforge](https://curseforge.com/minecraft/mc-mods/sodium-leaf-culling) - Не рендерит внутренние грани листвы, скрытые от камеры.
- `ImmediatelyFast` [modrinth](https://modrinth.com/mod/immediatelyfast) / [curseforge](https://curseforge.com/minecraft/mc-mods/immediatelyfast) / [github](https://github.com/RaphiMC/ImmediatelyFast) - Батчинг рендера: HUD, текст и немедленные вызовы.
- `Entity Culling` [modrinth](https://modrinth.com/mod/entityculling) / [curseforge](https://curseforge.com/minecraft/mc-mods/entity-culling) / [github](https://github.com/tr7zw/EntityCulling) - Пропускает рендер сущностей и блоков за стенами.
- `More Culling` [modrinth](https://modrinth.com/mod/moreculling) / [curseforge](https://curseforge.com/minecraft/mc-mods/moreculling) / [github](https://github.com/FxMorin/MoreCulling) - Куллинг частиц, карт, фонарей и других объектов.
- `Dynamic FPS` [modrinth](https://modrinth.com/mod/dynamic-fps) / [curseforge](https://curseforge.com/minecraft/mc-mods/dynamic-fps) / [github](https://github.com/juliand665/Dynamic-FPS) - Ограничивает FPS и звук, когда окно свёрнуто или в фоне.
- `Jade` [modrinth](https://modrinth.com/mod/jade) / [curseforge](https://curseforge.com/minecraft/mc-mods/jade) / [github](https://github.com/Snownee/Jade) - Панель с информацией о блоке или сущности под прицелом.
- `JEI` [modrinth](https://modrinth.com/mod/jei) / [curseforge](https://curseforge.com/minecraft/mc-mods/jei) / [github](https://github.com/mezz/JustEnoughItems) - Просмотр рецептов крафта и списков предметов.
- `Nemo's Inventory Sorting` [modrinth](https://modrinth.com/mod/nemos-inventory-sorting) / [curseforge](https://curseforge.com/minecraft/mc-mods/nemos-inventory-sorting) / [github](https://github.com/NemoNotFound/NemosInventorySorting) - Сортировка инвентаря и контейнеров по заданным правилам.
- `Cloth Config API` [modrinth](https://modrinth.com/mod/cloth-config) / [curseforge](https://curseforge.com/minecraft/mc-mods/cloth-config) / [github](https://github.com/shedaniel/cloth-config) - Библиотека экранов конфигурации (нужна More Culling).
