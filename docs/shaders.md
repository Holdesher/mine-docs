# Shaders

- `BSL` [modrinth](https://modrinth.com/shader/bsl-shaders) / [curseforge](https://curseforge.com/minecraft/shaders/bsl-shaders) - Яркий реалистичный шейдер: мягкие тени, облака, вода.
- `Photon` [modrinth](https://modrinth.com/shader/photon-shader) / [curseforge](https://curseforge.com/minecraft/shaders/photon-shader) - Полуреалистичный шейдер с акцентом на геймплей.
- `Solas Shader` [modrinth](https://modrinth.com/shader/solas-shader) / [curseforge](https://curseforge.com/minecraft/shaders/solas-shader) / [github](https://github.com/Septonious/Solas-Shader) - Фэнтези-стиль с цветным освещением и мягкой картинкой.
- `Complementary Shaders` [modrinth](https://modrinth.com/shader/complementary-reimagined) / [curseforge](https://curseforge.com/minecraft/shaders/complementary-reimagined) / [site](https://complementary.dev/shaders) - Детальный шейдер, близкий к ванильному стилю.
